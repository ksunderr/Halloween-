# Halloween Castle — Interactive Board

Интерактивная HTML-карта Halloween Castle: зоны площадки, механики квестов, персонал, реквизит, тайминг и вопросы для обсуждения.

## Открыть

Когда GitHub Pages включён: https://ksunderr.github.io/Halloween-/

## Однократная настройка GitHub Pages

1. Откройте https://github.com/ksunderr/Halloween-/settings/pages
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Branch: **main**, folder: **/(root)**. Нажмите **Save**.
4. Дождитесь статуса опубликованного сайта на этой же странице и откройте ссылку выше.

Сайт статический, собран в одном `index.html`. Никаких npm-команд, серверов и платных сервисов не требуется.

На телефоне: перетаскивание карты одним пальцем; кнопки `+` и `−` меняют масштаб, меню вверху прокручивается вбок. Кнопка «Обзор» возвращает общий вид.

Список закупок для Ксюши: https://docs.google.com/document/d/1bvOOre18qKLF-_ccLX8PYXQdLorufIrP5-oWm6LyvM8/edit
